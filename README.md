# 📊 Zepto Product Catalog – Descriptive Analytics

A data analytics project focused on exploring Zepto's product catalog to understand **product assortment, pricing, discounts, stock availability, inventory value, and category-wise patterns**.

## 👨‍💻 Author

**Ashar Abbas**  
BCA – Data Science & Artificial Intelligence  
BBD University, Lucknow

---

## 📌 Project Overview

This project performs descriptive analytics on a Zepto product catalog dataset containing **3,732 product records across 14 categories**.

The analysis transforms raw product-level data into meaningful insights using Python, statistical analysis, and data visualization.

> **Note:** The dataset represents catalog/inventory-level data rather than real-time customer order or transaction data.

---

## 🎯 Objectives

The project aims to analyze:

- Product distribution across categories
- Average selling price by category
- Average discount percentage
- Stock availability and out-of-stock rates
- Selling price distribution
- Price and discount bands
- MRP vs selling price relationship
- Products with the highest discounts
- Most expensive products
- Product weight distribution
- Correlation between numerical variables
- Inventory value by category
- Low-stock products and stock-out risk
